# Leo on the Hill

A pixel-art short film. Maryam is lying in a daisy field with one song on loop
and an earbud in. A ginger cat named Leo turns up with opinions.

Three minutes. Two endings, decided by the answers you pick.

- `index.html` — the whole thing. One self-contained file, no build step.
  Everything is drawn procedurally on a canvas and every sound is synthesised
  in the browser. The only external request is the Google Fonts stylesheet.

**Headphones on.** The world is deliberately muffled while her earbud is in,
and opens up the moment she takes it out.
